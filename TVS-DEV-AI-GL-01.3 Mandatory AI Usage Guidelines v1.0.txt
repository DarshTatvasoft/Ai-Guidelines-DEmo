CLAUDE.md / AGENTS.md  What   Root instructions file the AI reads at the start of every session.  Why   Without it, AI guesses your conventions   —   the top cause of   "works, but wrong"   changes.  Example   "Never edit tax logic without updating the audit - log module"   —   catches connected changes  before they're missed.  CI / PR template config  What   A PR template plus a CI check that enforces the guardrail checklist before merge.  Why   A checklist enforced by CI   can't be skipped under deadline pressure   —   one living only in a doc  can.  Example   GitHub Actions blocks the merge if the PR is missing its impact - radius note.

TatvaSoft   Mandatory AI Usage Guidelines   TVS - DEV - AI - GL - 01.3 | v1.0 | 25.09.2026  TVS · Internal   Page   6   of   7  Knowledge graph index  What   A pre - built map of symbols, calls, and imports the AI queries instead of guessing.  Why   This is what actually catches   "3 changed, 2 missed"   —   text search alone misses indirect  coupling.  Example   Graphify/Graphiti indexing a legacy billing module so "what calls this" is a lookup, not a 20 -  minute search.  Recommended  Build next, high value once the mandatory floor is in place.  skills/*.md  What   Documented, reusable playbooks for tasks the team repeats often.  Why   Stops the same task being done differently depending on who   —   or which AI session   —   runs it.  Example   A shared "add a field and propagate it" skill that always includes the knowledge - graph lookup  step.  agents/*.md  What   Definitions for narrower, specialized AI roles instead of one generalist assistant.  Why   A dedicated impact - analysis role is more reliable than trusting a generalist to remember to  check.  Example   A PR - reviewer subagent that only checks diffs against the guardrail checklist.  mcp.json  What   Connects the AI to real systems   —   Git, Jira, CI, databases   —   via the Model Context Protocol.  Why   Lets AI act on   live project state   instead of guessing from stale, copy - pasted context.  Example   An MCP link to Jira so AI pulls the actual acceptance criteria for a ticket.  docs/ (README, ARCHITECTURE.md)  What   The project's existing human - written architecture notes and decision records.  Why   Gives AI   —   and new hires   —   the   "why"   behind decisions that code alone doesn't explain.  Example   "Payments was split from orders in 2022 for PCI compliance" stops an AI refactor from  recombining them.
